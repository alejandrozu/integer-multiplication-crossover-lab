# Ordering the independently derived endpoints

This comparison does not require a monotone history and does not estimate an
unknown first crossing. Every entry retains its own declared literal family,
the same optimized GMP reference and the same positive XOR/AND tariff.

Suppose an earlier source has a necessary endpoint

    L=2^(2^h-2^69+q), h>70, q>=0,

and a later source has a sufficient eventual endpoint U=2^(2^P), P<=h-1.
Then2^P<=2^(h-1)<2^h-2^69+q, so U<L. At U the later declared family has a
correct member that strictly wins under its retained contracts. The earlier
declared family has no strict win at any integer input below L. Consequently
the later family's earliest attainable strict win precedes the earlier one.
The comparison is uniform in every positive XOR/AND tariff.

The chart applies this exact integer test only to independently bound
certificates with this explicit encoding. It preserves the PR's merge order
and does not compare a later entry with an earlier timestamp in reverse.
It neither turns the sufficient upper into a measured crossing nor proves
that every intervening entry improved. A compiler constant can improve this
comparison without increasing kappa. Other implementations, optimized or
compressed cores and smaller suppliers remain outside these family bounds.
