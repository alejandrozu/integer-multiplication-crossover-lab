# Necessary prefixes for four own selected literal finite covers

This separate component concerns the exact own selected source constructions of
PR533, PR538, PR569 and PR571. They were open cost rows when this component was
started. It supplies a necessary prefix only, not a sufficient upper, a validated
record, an exact crossing, or a proof that the original whole algorithms work.
The exact whitelist is fixed in the input snapshot. Other legacy packages are
not admitted by this proof.

The model is `xag-straightline-v1`, with one AND charged one unit and one XOR
charged the same arbitrary positive tariff rho in both circuits. The reference
is the unchanged `gmp-630-native-skylake-unbounded-exact-constants-v2`. Its closed
compact upper proves, separately for each gate type,
`GMP(n) <= 2^1875 (n+1)^8`. This improves the proof of the same reference's cost;
it does not choose a new comparator, compiler or hardware model.

## The comparison family and the active floor

The family is the available source-selected **literal complete-cover**
enhancement. Every active native invocation executes every source cover vertex
and retains at least one actual distinct public-main unit scalar ADD from its
selected word, with the stipulated guarded width at least two and literal ADD
lowering. It permits no cover quotienting, word pruning, CSE, constant folding,
scalar aggregation, native bypass or resynthesis that removes that instruction.
These alternatives are outside the family; their impossibility is not claimed.
The actual words in both orientations are scanned. A public-main role lies
below `2*v`; helpers and owned private centers do not. Positive denominator,
unit coefficient, distinct roles and the actual canonical namespace are all
checked. Keeping one of these source instructions is not artificial padding.

For comparison policies using no such native invocation, the family explicitly
returns the **identical fixed GMP reference**. This inactive rule is an extra
comparison-family definition, not an assertion about every historical base
case. All valid public switching policies in this family are included. There
is no chosen activation or sufficient-proof gate in the lower argument.
No statement here says that every policy eventually wins.

Let `V = |O(73,2)|`. The characteristic vector of the standard binary dot
product in odd dimension73 is fixed and anisotropic. Its complement is a
nondegenerate alternating72-dimensional space; restriction and extension
identify O(73,2) with Sp(72,2). Counting symplectic bases gives

`V = 2^(36^2) * product_(i=1..36) (2^(2*i)-1)`.

The exact integer has2628 bits, so `2^2627 <= V < 2^2628`. One retained real
ADD at each actual cover vertex costs at least one AND and three XORs at
guarded width at least two. Therefore an active body has AND >= V and
XOR >= 3V. No multiplication by2^73, coefficient-field coordinate volume,
number of calls, stock factor, productive rank, or invoice upper is used.
In particular a stock allowance alone would not prove mandatory work.

For any integer input width `1 <= n < L = 2^94`, `n+1 <= L`. Each reference
gate count is thus at most
`2^(1875+8*94) = 2^2627 <= V`.
For every rho>0, the active candidate costs at least `(1+3*rho)V`, strictly
more than the reference upper `(1+rho)V`; the difference is `2*rho*V > 0`.
An inactive branch equals the reference and cannot strictly beat itself.
Thus **every valid policy in the declared literal family has no strict win
for n < 2^94**. This is the exact necessary prefix proved here. The endpoint
is not claimed to be feasible, optimal or an actual first crossing.
