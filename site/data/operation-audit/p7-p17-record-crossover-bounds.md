# Own-source p7/p17 record crossover bounds

This new bundle instantiates a counted integer multiplier separately for PR4416,
PR4440, PR4441, and PR4447. It retains each PR's actual native supplier, tensor
power, completed productive floor, paid cutoff, authenticated sufficient uniform
rank, and uniform saving. It does not substitute the later p16 supplier. The
conclusions are conditional on the named all-column native and analytic contracts;
the finite source/type/arithmetic checks are not a new full operator identity
replay, Lean theorem, or human verification.

The model is the existing straight-line XOR–AND circuit model, AND=1 and XOR=rho
for every rho>0. The comparator is exactly the repaired unbounded native-profile
GMP reference, `gmp-630-native-skylake-unbounded-exact-constants-v2`. A declared
literal enhancement uses this comparator unchanged while its own core is inactive,
and executes the complete, unreduced native scalar word on the full ambient field
while active. The lower bound concerns every policy in this fixed family. It is
not a lower bound on compressed circuits, smaller-rank substitutes, or every
algorithm inspired by the PR.

## Primary source and fresh checks

Every cached primary file is pinned to the PR's own historical head, listed in
`p7-p17-record-source/*manifest.json`. The reproducer hashes these manifests and
all their files. It reconstructs complete raw target/paid profiles directly from
the emitted controller, including all query-only calls and complete idle windows.
For PR4441 and PR4447 it uses their own authenticated changed helper and paid
profiles, rather than pretending the controller alone fixes those profiles.
The source's original all-column identities, absolute phases, matching cleanup,
and native retiming correctness remain explicit premises.

The checker freshly validates binary invertibility, phase domains, dyadic scalar
coefficients and the serialized affine-quadratic Clifford grammar in the cached
native catalogs. It also checks the p7 routing recipe algebra: the eight local
orthogonal axes are perpendicular to q, their swaps into each fresh block are
orthogonal involutions fixing q, and untouched axes remain fixed. A Z4 parity
phase has even quadratic cross coefficients, so these recipes are Clifford maps.
The p17 query shear copies into an owned bank, calls its rank-one kernel, adds to
the other independent role, and erases the bank; it is charged as an owned scalar
construction, rather than asserted to be a unitary shear on two roles.

Each controller has at least four literal unit complex ADD operations in its
explicit boundary programs. These give eight real ADD operations per full-field
position. At width w>=2 the prescribed truncated ADD has at least one AND and
three XORs. Positive rank mass survives tensoring, completion and disjoint splitting;
a strict winning supplier must use a raw unit. Its ambient field has at least
2^N positions. Thus an active literal core costs at least
`8*(1+3*rho)*2^N`. Combining the existing source-specific degree-eight GMP upper
gives the necessary lower endpoint

`L = 2^(2^(H-3) - 2^69)`.

No strict win is possible for n<L in this family. This is a source-word work
obstruction independent of a selected switching gate. It neither says the core
cannot activate below L nor claims that this obstruction is sharp.

## Fresh finite compiler and precision constants

For raw productive/paid counts B,P, paid rank mass M_p, ambient rank m, tensor
power v, and completed floor f^v, define the exact integers

```
R = [10^9*v*(B+P)^v + M_p^v + B^v*f^v] * [10*m^(2v)+10],
K = 32*(R+1),   k = bit_length(K),   l = floor(log2(f^v)).
```

The source raw scalar/controller allowance is below 10^9. The final factor
counts an explicit affine/quadratic Clifford normal form on at most m*v axes;
10*m^(2v)+10 deliberately overpays the polynomial normal-form gate count. Native
warps and newly exposed monomial routes are charged, and owned roles, complete
external spectators, absolute phases and chronological barriers remain required.

The normalized rank-mass telescope gives G/W<K^2*N. A compiler child rank
contracts by at least 1/m^v, so J=m^v*H bounds depth. Chronological nested calls
can synchronize denominator-clearing replicas at the original flow stages; their
number does not multiply maximum wire height. With g=floor(H/l), the Clifford
stack guard is bounded by

`2^20*K^2*(g+1)*(J+1) < 2^Eguard`,

where `Eguard=22+2*k+bit_length(g+1)+bit_length(J+1)`.

The divisor-preserving width/inventory recurrence gives
`log2 D_N < N*[2*k+H*(1+k/l)] < 32*H*N` for all four actual parameter sets.
This fresh bound replaces the later p16-specific 9HN inequality. Only
`log2(log2 W+1)<2H` is subsequently needed. Base scalar words, separated field
roles, whole-job contracts and every denominator-clearing copy are retained.

## Own record tails and a common early protocol

Each record-tail branch freshly evaluates all 54 strict source predicates, its
actual three (p7) or four (p17) functional predicates, and nine source savings.
The p7 source BIT admission is .0027; p17 is .0034 with its actual .004 atom.
The optional finite-field BIT wrapper is not used by this direct Gaussian/Boolean
construction, so no unrelated denominator-exclusion census is borrowed.

For each tail, take its actual outer stop delta, Q=ceil(1/delta), and A=4Q+1.
This matters for PR4440, whose delta is 3/70000000, not a reciprocal integer.
The early branch uses the shared external protocol kappa_eff=1/500,
delta=1/10000, A=10001, q=.0023, a=.0024, b=.0025. Its native uniform saving
remains the PR's actual value, which is greater than .0026. All outer predicates
and all seven cost rows are evaluated afresh; the source exponent is metadata for
the record tail, not an invented saving for the early branch.

In either branch set

`E=Q*(H+1)+2H+2k+Eguard+179200000000+1048576+1000`,
`X=A*E`, and `U=2^(2^(X-8))` bits per operand.

The seven ledger rows are the existing counted interfaces for the target FFT,
twiddles, Gaussian H layers, diagonals, Strassen boundary solver, halos, and exact
recovery/carries. The candidate-only explicit Fermat helper is used for integer
products. Its extra eight logarithm powers and coefficient allowance are included.
The checker verifies every row's exact rational residual below -1, its finite
coefficient and monotone tail, precision normalization/rounding guards, stock
bases, X>128Q, X>=2^54, and fine-prime axis capacity. It does not transplant a
numerical prime gate that depends on an earlier delta. These conditions give
per-type cost at most n*p^(1-kappa_branch) for p=256*ceil(log2 n), hence a strict
win over both the specified GMP reference and the canonical counted HvH circuit
at every n>=U and every rho>0.

The full enhancement uses its early branch until its own record-tail upper gate,
then its own source record branch. Thus the common protocol improves finite
sufficient bounds while preserving each original asymptotic record exponent.
The resulting interval is a necessary family lower endpoint and a sufficient
family upper endpoint, not the actual first crossover or a practical hardware
benchmark. All retained framework contracts are enumerated in the JSON output.
