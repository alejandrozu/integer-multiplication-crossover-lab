Restore one complete folder

  1. Download all ZIP parts listed below, reproduction-package.json and restore_reproduction.py into the same folder.
  2. Open a terminal in that folder. Python 3.11 or later is sufficient. Restore into a new folder:
    python restore_reproduction.py --output cost-audit
  3. The tool checks every archive, source object and restored path against SHA256. It works offline and refuses an existing output folder.
  4. Open cost-audit/operation-audit and run the relevant proof scripts. For example:
    python t21_t37_finite_controller_upper.py
python gaussian_only_selected_provider_bounds.py
  5. Read the linked proof and peer receipt for each bound. Native, analytic and all-size realization premises remain explicit. Successful arithmetic checks do not establish an exact first crossover.
